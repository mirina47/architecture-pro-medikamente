# Список проблем компании в разрезе работы с данными

## 1. Организационные проблемы
- Не назначено ответственное лицо за обработку персональных данных и медицинской тайны.

- Отсутствуют внутренние политики, регламенты и инструкции по защите конфиденциальной информации.

- Не проведена оценка соответствия требованиям 152-ФЗ и Приказа №21.

- Нет формализованной процедуры получения и хранения согласий пациентов на обработку данных.

- Сотрудники не проходят регулярное обучение по защите персональных данных и ответственности за утечки.

## 2. Технические проблемы
- Данные хранятся в Excel, общих папках и локальных файлах без централизованной системы управления.

- Данные не шифруются при хранении и передаче.

- Отсутствует детальное разграничение прав доступа, сотрудники имеют доступ к чужим данным.

- Не ведётся аудит действий пользователей с конфиденциальной информацией.

- Интеграции с 1С, лабораториями и другими системами используют небезопасные способы обмена данными.

## 3. Процессные проблемы
- Использование Excel и ручного ввода приводит к дублированию и рассинхронизации данных.

- Медицинские документы хранятся без классификации и правил хранения.

- Не установлены сроки хранения и удаления персональных данных.

## 4. Юридические и риски безопасности
- Хранение врачебной тайны в открытом виде нарушает требования законодательства РФ.

- Возможны крупные штрафы, приостановка деятельности и потеря лицензии при утечке данных.

- Высокий риск репутационных потерь при разглашении медицинской тайны.

- Не ведётся мониторинг подозрительных действий пользователей.

## 5. Проблемы масштабирования и развития
- Текущая архитектура не рассчитана на рост объёма данных и открытие филиалов.

- Отсутствует централизованное хранилище данных для BI, ML и AI-аналитики.

- Нет защищённых API и механизмов безопасного доступа для портала пациента и мобильного приложения.

- Не реализованы автоматические уведомления и онлайн-подтверждение записей.

- Отсутствуют CI/CD и автоматические проверки безопасности при разработке новых сервисов.

## 6. Рекомендации по приоритетам
- Назначить ответственного за обработку персональных данных и разработать внутренние политики безопасности.

- Перейти на централизованную СУБД с шифрованием и отказом от хранения данных в Excel.

- Настроить ролевую модель доступа и аудит действий пользователей.

- Внедрить шифрование каналов передачи данных и безопасные API для интеграций.

- Внедрить мониторинг утечек и аномальных действий пользователей.
